## Лабораторна робота 2

### Порівняння режимів публікації
| RID | Режим | Розмір publish | Потрібен runtime |
| :--- | :--- | :--- | :--- |
| win-x64 | Self-contained | 72 МБ | Ні |
| win-x64 | Framework-dependent | 0.185 МБ| Так (.NET 10) |

- **Self-contained**: пакує застосунок разом із віртуальною машиною .NET Runtime та базовими бібліотеками. Застосунок повністю автономний, але займає багато місця на диску.
- **Framework-dependent**: містить лише скомпільований код застосунку та зовнішні залежності. Має компактний розмір, але потребує відповідної версії .NET Runtime на машині користувача.


## Лабораторна робота 3: Імпорт даних

### Формат файлу даних (`data/sample.csv`)
- **Кодування:** UTF-8
- **Роздільник колонок:** `;` (крапка з комою)
- **Заголовок:** присутній у першому рядку (`id;sku;name;unit;quantity`), ігнорується парсером
- **Коментарі:** рядки, що починаються з символу `#`, ігноруються

#### Структура колонок:
1. `Id` — текстовий ідентифікатор товару (наприклад, `P-001`)
2. `Sku` — артикул товару (обов'язкове поле)
3. `Name` — назва товару (обов'язкове поле)
4. `Unit` — одиниця вимірювання (`шт`, `кг`, `м` тощо)
5. `Quantity` — кількість, ціле невід'ємне число (`>= 0`)
